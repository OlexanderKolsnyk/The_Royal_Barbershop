# The Royal Barbershop

Український сайт онлайн-запису та адмінпанель. Клієнтський інтерфейс — GitHub Pages; захищений шлюз — Cloudflare Worker через Sites; база — приватна Google Sheets; бізнес-операції — Google Apps Script.

## Швидкий старт

`node --test tests/*.test.mjs` — перевірки правил. `node scripts/build.mjs` — Worker, статичні ресурси й файли Apps Script. Зовнішніх npm-залежностей немає; потрібен Node.js 22+.

У Google Apps Script додайте `Core.gs`, `Initial.gs`, `Api.gs` і маніфест `appsscript.json`; заповніть Script Properties, виконайте `initialize`, `installMaintenance` та опублікуйте версію як Web App. Далі налаштуйте runtime-параметри шлюзу. Деталі: [розгортання](docs/DEPLOYMENT.md), [архітектура](docs/ARCHITECTURE.md), [обмеження й перевірки](docs/STATUS.md).
