# Керування The Royal Barbershop

- Сайт: https://olexanderkolsnyk.github.io/The_Royal_Barbershop/
- Адмінка: https://royal-barbershop-api.moltenheron4.chatgpt.site/admin
- Код: https://github.com/OlexanderKolsnyk/The_Royal_Barbershop
- Приватні дані: Google-таблиця власника; пряме посилання надане власнику окремо.
- Сервер: проєкт The Royal Barbershop — Backend у Google Apps Script власника.

## Вхід

На головній сторінці швидко натисніть корону 7 разів. Або відкрийте адмінку напряму. Введіть збережений пароль барбершопу. Email, Google або ChatGPT-акаунт для щоденного входу не потрібні. Не надсилайте пароль у чат.

Секретний жест приховує посилання. Реальний захист — серверна перевірка пароля й випадковий ключ сесії. Будь-хто, хто знає цей пароль, має повні права власника: клієнти, фінанси, налаштування та експорт. Окремі ролі працівників у цьому режимі не застосовуються.

Пароль обробляється PBKDF2-HMAC-SHA256: 600 000 ітерацій у браузері, далі ще 100 000 на сервері з секретним pepper. Apps Script зберігає лише остаточний відбиток із випадковою сіллю. Відкритий пароль не передається на сервер. Відкритого пароля немає у репозиторії, таблиці, localStorage чи sessionStorage. Форма очищає поля після надсилання. Браузер або його менеджер паролів може окремо запропонувати збереження — цим керує власник браузера. HttpOnly/Secure cookie містить лише випадковий ключ сесії. Сесія завершується через годину або раніше, якщо серверний кеш очищено. Після 5 помилок — блокування на 15 хвилин для джерела спроб.

## Щоденна робота

- Календар: день, 3 дні або тиждень. Натисніть вільний інтервал для нового запису; картку можна перенести.
- Налаштування → Графіки: виберіть майстра й редагуйте тиждень. Окрема дата дозволяє вихідний, перерву або інші години.
- Налаштування → Майстри / Послуги / Ціни та тривалість: редагування каталогу.
- Доступи: один спільний пароль власника. Щоб відкликати доступ, змініть пароль — це завершить попередні сесії.
- Змінити пароль: кнопка в налаштуваннях власника. Зміна завершує всі попередні парольні сесії.
- «Вийти»: одразу завершує поточну сесію.

## Де що працює

GitHub зберігає код і публікує головний сайт. Sites виконує серверний шлюз та адмінку — звідси домен chatgpt.site. Apps Script звертається до приватної таблиці й перевіряє доступ. Окремий репозиторій не змінює хостинг чи домен. Власний домен можна підключити окремо.

Абсолютної гарантії безвідмовності немає: система залежить від GitHub, Sites і Google. Щоденні резервні копії, історія змін і журнал допомагають відновленню. Не змінюйте JSON-рядки в таблиці вручну: користуйтеся адмінкою, щоб зберігався аудит.

Якщо пароль загублено, власник Google Apps Script може у Script Properties видалити ADMIN_PASSWORD_HASH та ADMIN_PASSWORD_REVISION і задати новий пароль у формі після входу через акаунт власника. Це відновлення доступу слід робити лише власнику; GATEWAY_SECRET та інші властивості не змінюйте.
